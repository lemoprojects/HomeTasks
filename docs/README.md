# HomeTasks Documentation

Index of project documents. Each document is the source of truth for its area.

## Structure

- [`architecture/`](architecture/) — architecture, stack, costs, open decisions
  - [`tech-stack.md`](architecture/tech-stack.md) — full MVP technology stack
  - [`cost-estimate-mvp.md`](architecture/cost-estimate-mvp.md) — MVP cost estimate and scaling paths
  - [`open-decisions.md`](architecture/open-decisions.md) — decisions not yet resolved
- [`adr/`](adr/) — Architecture Decision Records (numbered, immutable after acceptance)

## Conventions

- Each significant architectural decision is captured in a separate ADR
- ADRs are immutable after acceptance — changing a decision = new ADR with status `Supersedes ADR-NNNN`
- Documentation is written in English
- Files are in Markdown format
- Dates use ISO format (YYYY-MM-DD)
